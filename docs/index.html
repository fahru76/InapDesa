Core Features

📅 Live Pricing Calendar

Guest-facing calendar with real-time availability, weekend/weekday pricing, and visual booking status.

💳 Secure Payments

Stripe Payment Element + optional Billplz for Malaysian e-wallets, FPX, and GrabPay.

🏠 Host Dashboard

Complete booking management, guest communication, calendar sync (Airbnb/Agoda/Booking.com), and content editor.

🔐 Security & Trust

Row-Level Security on all data, idempotent webhooks, verified reviews, security deposits, and cancellation presets.

🌍 Multi-Language

Guest-facing interface in English and Bahasa Melayu with localized dates and amounts.

📱 Responsive Design

Beautiful on desktop and mobile. Progressive disclosure with bottom-sheet booking on phones.
